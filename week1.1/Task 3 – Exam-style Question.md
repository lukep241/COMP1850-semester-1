**Task 3 – Exam-style Question**


Version control systems such as Git are widely used in software development.

State two advantages of using version control when writing software. Explain each point from:

• the perspective of an individual programmer;

• the perspective of working in a team developing software.

**--------------------**
**An advantage of using version control for an individual programmer is that they are able to track and observe the history of their source code. They can restore previous versions of their work. This is useful for working on large projects by yourself as there will always be a backup of the successful states of the code to backtrack to.** 



**Another advantage is that when working in a team, you can make you own changes to a repository on a local code space and then commit your changes back to the shared repository without affecting anyone elses work/changes. This is because each commit represents the same project but in a different state that is still visible to other team members. Members can view and work off of the changes made by others once they are done. Version control promotes collaboration.** 
**--------------------**		



State one disadvantage of Git. You can write this from either:

• your own perspective;

• the perspective of a new programmer who has just been introduced to it.

You may use external resources to help you, but answers must be written in your own words.

**--------------------**
A disadvantage of using git is that for a new programmer, it may be very difficult at first to learn how it works and to understand its features. If they are used to having a single project file and saving changes as they are made, transitioning to Git version control may be overwhelming due to the large amount of useful functions that that may need to learn.
